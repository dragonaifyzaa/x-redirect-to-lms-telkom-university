# X → LMS Telkom Extension

Browser extension (Chrome/Edge) that automatically redirects `x.com` and `twitter.com` to Telkom University LMS (`lms.telkomuniversity.ac.id/my/`).

---

## Installation

1. Download and extract the extension folder
2. Open `edge://extensions/` or `chrome://extensions/`
3. Enable **Developer Mode**
4. Click **Load unpacked** → select the extracted folder
5. Extension is ready to use

---

## Usage

- Open `x.com` or `twitter.com` → automatically redirected to LMS
- Click the extension icon in the toolbar to toggle redirect ON/OFF
