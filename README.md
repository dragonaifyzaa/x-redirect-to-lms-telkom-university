# X → LMS Telkom Extension

Browser extension (Chrome/Edge) yang otomatis redirect `x.com` dan `twitter.com` ke LMS Telkom University (`lms.telkomuniversity.ac.id/my/`).

---

## Installation

1. Download dan extract folder extension ini
2. Buka `edge://extensions/` atau `chrome://extensions/`
3. Aktifkan **Developer Mode**
4. Klik **Load unpacked** → pilih folder hasil extract
5. Extension siap digunakan

---

## Usage

- Buka `x.com` atau `twitter.com` → otomatis diredirect ke LMS
- Klik icon extension di toolbar untuk toggle redirect ON/OFF
